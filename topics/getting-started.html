Getting Started

How this site is organized and how to add new content.

Site structure

maximumtrainer.github.io/
  index.html          ← home page
  topics/
    getting-started.html  ← this page
    your-new-topic.html   ← add pages here

Adding a new topic

  1. Create a new .html file in the topics/ directory. Use this page as a template.
  2. Add a link to your new topic in the Topics section of index.html: 
    <a href="topics/your-topic.html" class="topic-card">
  <h3>Your Topic Title</h3>
  <p>A short description.</p>
</a>
  3. Commit and push to main. GitHub Pages will publish automatically.

Local preview

Open index.html directly in a browser, or serve it locally:

python3 -m http.server 8000

Then visit http://localhost:8000.

Customization

The site uses plain HTML and CSS with no build tools or dependencies. Styles are defined inline in each page using CSS custom properties, making them easy to update in one place. Dark mode is supported automatically via prefers-color-scheme.
